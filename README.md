# CrowdVision

CrowdVision — Android-приложение для обработки видеопотока с помощью машинного обучения.

Приложение выполняет детекцию людей в реальном времени, отслеживает их на видео, присваивает ID, считает количество людей в кадре и сохраняет аналитику по сессиям наблюдения.

## Основные возможности

- создание сессий наблюдения;
- детекция людей в реальном времени;
- трекинг людей с присвоением ID;
- подсчёт людей в кадре;
- подсчёт уникальных посетителей в рамках сессии;
- сохранение аналитики по сессиям;
- просмотр статистики и графика;
- добавление и редактирование заметок по сессиям;
- удаление сессий;
- офлайн-работа без интернета.

## Технологии

- Kotlin
- CameraX
- TensorFlow Lite
- YOLOv8
- трекинг объектов
- Room
- MPAndroidChart

## Установка приложения

1. Перейдите в раздел **Releases**.
2. Скачайте файл `app-release.apk`.
3. Установите APK на Android-устройство.
4. Разрешите доступ к камере при первом запуске.

## Структура приложения

- **Главный экран** — список сессий наблюдения
- **Создание сессии** — ввод названия, места и заметки
- **Экран камеры** — обработка видеопотока и аналитика
- **Детали сессии** — график, статистика, заметки

## Инструкция пользователя

1. **Создание сессии** — нажмите «Создать сессию», введите название, место и заметку.
2. **Запуск наблюдения** — выберите сессию, нажмите «Камера», затем «Начать».
3. **Просмотр результатов** — на главном экране нажмите «Детали» для выбранной сессии.
4. **Редактирование заметки** — на экране деталей измените текст и нажмите «Сохранить заметку».
5. **Удаление сессии** — на главном экране нажмите на значок корзины.
